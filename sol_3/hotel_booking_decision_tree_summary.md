# 酒店预订取消预测 - 自定义决策树实现总结

## 项目概述

本项目基于 `house_predict.py` 的实现，为酒店预订取消预测任务开发了一个自定义决策树模型。该模型专门针对酒店预订数据的特点进行了优化，包括特征工程、数据预处理和决策树算法的改进。

## 数据集分析

### 数据规模
- **训练样本**: 25,417 条记录
- **测试样本**: 10,858 条记录
- **特征数量**: 17 个原始特征 + 7 个衍生特征 = 24 个特征
- **标签分布**: 
  - 不取消 (0): 17,034 样本 (67.02%)
  - 取消 (1): 8,383 样本 (32.98%)

### 特征类型
1. **数值特征**: 14 个
   - 客人数量、住宿天数、价格、提前期等
2. **分类特征**: 3 个
   - 餐食计划、房间类型、市场细分

## 核心改进

### 1. 数据预处理优化

#### 分区间策略
针对酒店预订数据的特点，设计了专门的分区间策略：

```python
HOTEL_BINNING_STRATEGIES = {
    'avg_price_per_room': {'strategy': 'quantile', 'n_bins': 8},
    'lead_time': {'strategy': 'quantile', 'n_bins': 8},
    'no_of_week_nights': {'strategy': 'equal_width', 'n_bins': 6},
    'no_of_weekend_nights': {'strategy': 'equal_width', 'n_bins': 6},
    # ... 更多特征
}
```

#### 特征工程
创建了7个有意义的衍生特征：

1. **总住宿天数** (`total_nights`): 工作日 + 周末天数
2. **总客人数量** (`total_guests`): 成人 + 儿童数量
3. **提前期分类** (`lead_time_category`): 短期(≤7天)、中期(≤30天)、长期(≤90天)、超长期(>90天)
4. **价格区间分类** (`price_category`): 低价、中低价、中价、中高价、高价
5. **客户忠诚度评分** (`loyalty_score`): 基于重复客户和历史预订记录
6. **风险评分** (`risk_score`): 综合提前期、价格和特殊请求
7. **季节性特征** (`season`): 基于到达月份的季节分类

### 2. 决策树算法优化

#### 核心改进
1. **向量化计算**: 使用 `np.bincount` 和向量化操作提高计算效率
2. **特征采样**: 支持 `sqrt`、`log2` 等特征采样策略
3. **增益阈值**: 降低信息增益阈值至 0.001，允许更细粒度的分割
4. **样本数检查**: 在分割后检查左右子树的样本数，避免过拟合

#### 参数配置
```python
config = {
    'max_depth': 15,           # 增加树深度
    'min_samples_split': 20,   # 降低分割最小样本数
    'min_samples_leaf': 10,     # 降低叶节点最小样本数
    'max_features': None,       # 使用所有特征
    'criterion': 'entropy'      # 使用信息熵
}
```

### 3. 可视化功能

#### 决策树结构可视化
- 支持自定义深度显示
- 颜色编码：蓝色(内部节点)、绿色(不取消)、橙色(取消)
- 显示特征名称和阈值

#### 特征重要性分析
- 水平条形图显示 Top N 重要特征
- 数值标签显示具体重要性分数

#### 混淆矩阵
- 热力图显示预测准确性
- 支持中文标签

## 关键特征分析

根据分析报告，最重要的特征包括：

1. **lead_time** (提前期): 与取消率呈强正相关
2. **no_of_special_requests** (特殊请求): 与取消率呈强负相关
3. **market_segment_type** (市场细分): 高度显著
4. **avg_price_per_room** (房间价格): 中等正相关
5. **repeated_guest** (重复客户): 与取消率呈负相关

## 业务洞察

### 高风险客户识别
- 提前期超过90天的客户 (55.87% 取消率)
- 100-150价格区间的客户 (42.06% 取消率)
- 无特殊请求的客户 (43.41% 取消率)
